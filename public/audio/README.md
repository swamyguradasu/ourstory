# User-Supplied Ambient Audio Files

Place your royalty-free / personal ambient audio files in this directory:

- `our-story.mp3` - Main ambient theme
- `map-ambient.mp3` - Gentle map background
- `distance.mp3` - Quiet acoustic or piano theme
- `reunion.mp3` - Golden hour reunion theme

If these files are absent, the application gracefully remains silent without throwing errors.
